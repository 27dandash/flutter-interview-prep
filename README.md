# Flutter Interview Ladder

214 Flutter & Dart interview questions (Arabic), ordered Junior → Mid → Senior, with problem solving, HR questions, a timed mock-interview mode, and a "What's new" timeline for every Flutter version from 3.0 to 3.50, plus what changed in Flutter/Dart 2024–2026. Each answer can be shown or hidden, and you can rate yourself on every question.

**Live:** https://27dandash.github.io/flutter-interview-prep/
